# 开店筹备与选址

开店进货更名为开店筹备，保留原有账单数据、接口与 setup_purchase 权限标识，无需迁移数据库。

- /setup-purchases 默认显示进货账单，选址分析与新建账单按钮在标题右侧并排展示。
- 选址分析使用居中弹窗，地图由原生 React 组件 StoreLocationMap 渲染，关闭后可重新打开。
- /setup-purchases/location 提供独立选址页面，沿用模块和选址权限校验。

地图统一使用系统 NEXT_PUBLIC_AMAP_KEY 与 NEXT_PUBLIC_AMAP_SECURITY_CODE，不提供页面密钥配置。高德平台需允许系统实际访问域名。当前保留地点搜索、地区定位、点位与半径、行政区轮廓、覆盖面积和重叠率分析、底图与图层、导入导出功能，不加载人口数据。

点位、地区及地图偏好按账号保存在本机浏览器，不跨设备同步。旧版共用缓存原样保留，不自动划归任何账号，也不会被新版读取。

## 权限分配

角色管理的开店筹备页面提供选址分析、创建、编辑、删除等操作权限。页面访问要求 setup_purchase:manage，选址另要求 setup_purchase:location。

旧角色未细分的操作权限继续继承管理权限，编辑器会展示继承值；明确保存为 false 的操作权限优先于兼容继承。新分配只开启页面访问时，其余操作默认关闭。未更改已保存的角色权限。

接口会校验模块及具体操作权限、批次归属、明细所属批次与账号、关联商品归属。跨账号或错误批次请求返回拒绝或不存在。

## 验证

运行 node scripts/setup-purchases-permissions.test.cjs 验证模块拒绝、细分角色开关、跨账号拦截、正常读写与本地缓存隔离。该检查使用模拟会话和数据库，不修改业务数据。

运行 TypeScript 检查及 Next.js 生产构建确认页面可编译；真实地图联网表现仍取决于高德配置、域名白名单和网络。
