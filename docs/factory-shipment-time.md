# 发货时间统计与上线回退

厂家发货页面和 Excel 导出的日期筛选使用备注中每件货品已有的 `trackingEntries.shippedAt`，按北京时间计算起止日期（包含边界）。同一单分批发货时，仅统计选定日期内的货品，汇总中的数量、货款和运费也仅计算这些货品。汇总时间列出各批次时间；明细保留单据创建时间作为辅助信息。

历史记录缺少或包含无效的发货时间时显示“未记录发货时间”，不回退到创建时间，不自动回填。未选择日期时保留这些记录；选择日期后排除。这里统计的是当前记录保存的货品发货时间，不是完整的发货事件流水。

页面桌面列表、移动列表、详情窗口与汇总明细均展示发货时间。列表按当前筛选命中货品的最近发货时间倒序排列，缺失时间的单据放在末尾。顶部统计卡、列表商品数量和金额跟随当前筛选；编辑与状态更新仍使用完整原始单据，筛选不会删除或改写单据货品。
